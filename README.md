# React Website

A modern, responsive website built with React, Vite, and Tailwind CSS. The project focuses on reusable components, interactive UI elements, and a clean design to create an engaging user experience.

## ✨ Features

- **Responsive Design** — Layout adapts to different screen sizes and devices.
- **Reusable Components** — Modular React components for maintainable and organized code.
- **Services Section** — Dedicated cards to showcase services, descriptions, and icons.
- **Interactive UI** — Dynamic hover effects and mouse-tracking gradient animations.
- **Contact Form** — Contact form with success and error notifications.
- **Dark Mode Styling** — Dark theme support using Tailwind CSS utility classes.
- **Modern Styling** — Tailwind CSS for flexible layouts, responsive utilities, and custom styling.

## 🛠️ Technologies Used

- **React** — Component-based user interface development.
- **JavaScript (ES6+)** — Application logic and interactivity.
- **Vite** — Fast development server and build tooling.
- **Tailwind CSS** — Utility-first CSS framework.
- **Motion for React** — Declarative animations and interactive UI transitions.
- **React Hooks** — State management and DOM references using hooks such as `useState` and `useRef`.
- **React Hot Toast** — User feedback through toast notifications.
- **Git & GitHub** — Version control and source code management.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Martynas-Mockapetris/React-Website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd React-Website
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, typically `http://localhost:5173`.

## 📦 Production Build

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

The generated production files are placed in the `dist` directory by default.
